# 🛍️ Clothing Store Project

A modern **full-stack e-commerce application** for clothing, built with **React** on the frontend and **Laravel REST API** on the backend. This project demonstrates a clean architecture, scalable design, and seamless integration between client and server.

---

## 🚀 Features
- **Frontend (React + Vite)**
  - Single Page Application (SPA) with React Router
  - Responsive UI for desktop and mobile
  - Product listing, filtering, and search
  - Shopping cart with add/remove functionality
  - Checkout flow with order summary
  - User authentication (login/register)

- **Backend (Laravel REST API)**
  - RESTful endpoints for products, categories, users, and orders
  - JWT-based authentication
  - Database migrations and seeders
  - Validation and error handling
  - Secure API design following best practices

---

🛠️ Tech Stack
| Layer        | Technology |
|--------------|------------|
| Frontend     | React, Vite, Axios, React Router |
| Backend      | Laravel, PHP, MySQL/PostgreSQL |
| Styling      | TailwindCSS / Bootstrap |
| Auth         | JWT |
| Deployment   | Docker / Nginx |
